One original joke about Monday mornings, at most 200 characters, written by a small Python program for make.fun's "Monday Morning Punchlines" bounty. The program writes the joke to `/output/entry.txt`; a judge model compares the jokes two at a time and picks the funnier one.

## Run it

```sh
python3 main.py
```
